# Johnpaul Portfolio

A responsive personal developer portfolio built with React and Vite.

## Tech stack

- React 18
- Vite
- Lucide React icons
- Custom responsive CSS
- Google Fonts: DM Sans and Space Grotesk

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Updating portfolio content

- Edit the project entries in the `projects` array in `src/App.jsx`.
- Update the skills in the `skills` array.
- Replace the profile image at `image/IMG_20260114_202638.jpg` if needed.
- Replace the CV at `assest/okoli sochimaobi.pdf` if needed.
- Update the email and social links in `src/App.jsx` when your contact details change.

The existing profile photo and CV are retained in this repository.
